## Getting started

1. `cd bootstrap && terraform init && terraform apply -var-file=bootstrap.tfvars` (or run the accelerator with `-Deploy`).
2. Push this repository to [[cicd_label]] and merge to `main` to deploy `infra/` through [[environments_csv]].
3. Run the `ml-train` pipeline, then `ml-deploy`.
