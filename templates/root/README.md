## Layout

| Path | Purpose |
|---|---|
| `bootstrap/` | One-time Terraform: remote state, federated identity, [[cicd_label]] project/repo wiring. |
| `infra/` | [[iac_label]] for the Azure ML workload, one parameter file per environment ([[environments_csv]]). |
| `src/` | Training code (prep, train, evaluate, register). |
| `mlops/azureml/` | Azure ML data, environment, pipeline and endpoint definitions. |
| `[[pipelines_dir]]/` | CI/CD definitions. |

## Getting started

1. `cd bootstrap && terraform init && terraform apply -var-file=bootstrap.tfvars` (or run the accelerator with `-Deploy`).
2. Push this repository to [[cicd_label]] and merge to `main` to deploy `infra/` through [[environments_csv]].
3. Run the `ml-train` pipeline, then `ml-deploy`.

## Pinned versions

Python [[versions.python]] with the exact package set in `mlops/azureml/conda.yml` and `requirements-dev.txt`.
These versions were resolved and exercised together by the accelerator; run
`Test-MLOpsAcceleratorVersion` to see what is out of date, and re-run the generator to pick up updates.

Private networking: [[private_networking]] (when `true`, public access is disabled on all resources; you must add
private endpoints and a VNet-reachable compute/agent before using the workspace).
